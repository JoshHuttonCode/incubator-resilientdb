# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you believe you have found a security vulnerability in Apache ResilientDB, please report it privately following the Apache Software Foundation security process:

https://www.apache.org/security/

If no project-specific private security address is available, reports may be sent to:

security@apache.org

Please include a clear description of the issue, affected versions or components, steps to reproduce if possible, and any suggested mitigation.

The Apache Security Team and the Apache ResilientDB project community will coordinate handling of valid reports according to the ASF vulnerability handling process.
